# Alenka Automation (Candy Forecast)

Проект представляет собой автоматизированную бизнес-систему для прогнозирования спроса и формирования бланков заказа. Он охватывает полный цикл разработки: от проведения ML-исследований и анализа данных до создания полноценного веб-приложения (REST API + SPA) для удобного взаимодействия с результатами.

## Стек технологий

**Backend (API & Логика):**
- **Python, FastAPI** — современный и быстрый асинхронный фреймворк для API.
- **PostgreSQL, SQLAlchemy (asyncpg), Alembic** — база данных, ORM и миграции.
- **Pandas, xlrd, openpyxl** — обработка файлов Excel и датасетов.

**Frontend (Пользовательский интерфейс):**
- **React 18, TypeScript, Vite** — сборка и типизированный UI.
- **TailwindCSS** — стилизация приложения.
- **React Query, React Table, Lucide React** — управление состоянием сервера, таблицы и иконки.

**ML / Analytics (Data Science):**
- **Pandas, Scikit-learn, XGBoost** — машинное обучение и работа с данными.
- **Jupyter Notebooks** — среда для проведения исследований.

**Инфраструктура:**
- **Docker, Docker Compose** — контейнеризация для быстрого и предсказуемого развертывания.

## Аналитика и ML-исследования (`src/analytics`)

В проекте проведен полноценный пайплайн исследования данных (EDA) и построения моделей, решающих реальную бизнес-задачу предсказания будущих заказов. Основные этапы работы:

- **Подготовка и валидация данных:** Очистка сырых данных продаж, проверка временных рядов на стационарность.
- **XYZ-анализ:** Сегментация ассортимента (SKU) по коэффициенту вариации, что позволяет применять разные алгоритмы прогнозирования в зависимости от стабильности спроса на конкретный товар.
- **Прогнозирование нерегулярного спроса:** Отдельная проработка сложных случаев с прерывистым спросом (Intermittent demand forecasting).
- **Обучение моделей:** Построение Baseline-моделей и применение **XGBoost** для повышения точности предсказаний.
- **Автоматизация бизнес-процессов:** Конвертация сырых ML-предсказаний в итоговые бланки заказа для поставщиков, расчет необходимого объема закупки с учетом текущих остатков.

## Запуск проекта

Проект полностью настроен для работы в Docker.

1. Убедитесь, что у вас установлен Docker и Docker Compose.
2. В корневой директории выполните команду:
   ```bash
   docker-compose up --build
   ```
3. Сервисы будут доступны по следующим адресам:
   - **Frontend (Пользовательский интерфейс):** http://localhost:8080
   - **Backend API (Документация Swagger):** http://localhost:8000/docs
   - **База данных (PostgreSQL):** порт 5432
